ama_cryptography.monitoring
===========================

Runtime security monitoring (the 3R mechanism) and the optional
agentic-abuse detectors — :class:`VolumeSpikeDetector` and
:class:`NoteArtifactDetector` — that back INVARIANT-30.  These are advisory:
they surface statistical anomalies and note-like signed payloads for review;
they never block a cryptographic operation.
